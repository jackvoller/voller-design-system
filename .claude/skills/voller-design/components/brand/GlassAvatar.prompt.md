Circular portraits, initials and round screenshot crops.

```jsx
<GlassAvatar src="/team/ana.jpg" alt="Ana" size={96} />
<GlassAvatar size={56}>V</GlassAvatar>
```

The ring is not decoration — it is the shared token from the app icons, so keep it on every circular image. On dark sections pass `onDark` to drop the ring alpha to .10/.22.
