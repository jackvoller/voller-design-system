Any panel, tile or grouped block of content.

```jsx
<Card tone="white"><h2>Riverly</h2><p>Navigation, simplified.</p></Card>
<Card tone="dark" interactive padding={20} radius="panel">…</Card>
```

`white` on a cream/field page, `cream` for a sunken step, `dark` inside a `--bg-dark` section. Never add a box-shadow for hierarchy — step the background or use the hairline.
