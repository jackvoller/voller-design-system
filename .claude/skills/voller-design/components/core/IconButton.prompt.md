Icon-only button for toolbars, nav and dismissals; always pass `label`.

```jsx
<IconButton label="Close"><X size={18} /></IconButton>
<IconButton label="Menu" variant="bare" size="lg"><Menu size={20} /></IconButton>
```

Use `lg` (44px) for anything touched on mobile. Icons come from Lucide at 1.75px stroke — see ICONOGRAPHY in readme.md.
